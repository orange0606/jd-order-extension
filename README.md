# 京东订单数据抓取浏览器插件

专为智查查风控系统开发的Chrome浏览器扩展，自动检测京东商家后台订单页面，一键抓取订单数据并同步到风控系统。

## ✨ 功能特性

- 🔍 **自动页面检测**：进入 `https://shop.jd.com/jdm/trade/orders/order-list` 自动激活
- 📦 **一键抓取**：自动解析当前页所有订单数据（订单号、金额、买家、商品、地址等）
- 🔐 **登录同步**：支持登录智查查系统，抓取后自动同步到后端
- 🎯 **悬浮面板**：页面内悬浮操作面板，不影响京东后台原有操作
- 💾 **本地缓存**：自动去重保存，支持离线抓取后批量同步
- ⚙️ **可配置**：支持自定义服务器地址、自动同步开关等

## 🚀 安装方法

### 1. 开发者模式加载（推荐开发调试）

1. 打开 Chrome 浏览器，地址栏输入：`chrome://extensions/`
2. 右上角开启 **「开发者模式」**
3. 点击左上角 **「加载已解压的扩展程序」**
4. 选择本项目文件夹 `jd-order-extension`
5. 扩展安装成功，会出现在扩展列表中

### 2. 固定到工具栏

1. 点击 Chrome 右上角拼图图标（扩展管理）
2. 找到「京东订单数据抓取助手」
3. 点击右侧图钉图标，固定到工具栏

## 📖 使用说明

### 第一步：登录系统

1. 点击扩展图标打开弹窗
2. 输入智查查系统的**服务器地址**（默认 `http://localhost:3000/api`）
3. 输入你的账号和密码
4. 点击「登录」按钮

### 第二步：抓取订单

1. 在浏览器中打开京东商家后台：
   ```
   https://shop.jd.com/jdm/trade/orders/order-list
   ```
2. 页面右上角会自动出现红色的「📦 订单抓取助手」悬浮面板
3. 点击「🔍 抓取当前页」按钮
4. 等待解析完成，会显示成功抓取的订单数量
5. 已登录状态下会自动同步到服务器

### 第三步：查看和同步

- 点击扩展图标可以查看：
  - 本地已缓存的订单数量
  - 最后同步时间
  - 当前页面状态
- 点击「🔄 立即同步到服务器」可手动触发同步
- 点击「🗑️ 清空本地数据」可清除本地缓存

## 🔧 后端接口对接

插件默认对接智查查Node.js后端，需要以下接口：

### 登录接口
```
POST /api/auth/login
Body: { username, password }
Response: { token, user }
```

### 批量导入订单接口
```
POST /api/orders/batch-import
Headers: Authorization: Bearer {token}
Body: {
  orders: [...],
  source: "jd_extension",
  shopName: "店铺名称"
}
```

### 订单数据字段说明

| 字段 | 说明 |
|------|------|
| orderId | 京东订单号 |
| orderTime | 下单时间 |
| buyerName | 买家账号/姓名 |
| productName | 商品名称 |
| quantity | 购买数量 |
| totalAmount | 订单总金额 |
| paymentAmount | 实付金额 |
| orderStatus | 订单状态 |
| receiverInfo | 收货人信息 |
| phone | 收货人电话 |
| address | 收货地址 |
| crawlTime | 抓取时间 |
| source | 来源标识（固定为 jd_shop） |

## ⚙️ 配置说明

在设置页面可以配置：

- **自动同步**：抓取完成后是否自动同步到服务器（默认开启）
- **抓取通知**：完成抓取后是否显示系统通知（默认开启）
- **服务器地址**：后端API地址，可根据环境修改

## 🐛 常见问题

### Q: 点击抓取没反应？
A: 请先刷新订单页面，确保页面完全加载后再点击抓取。京东后台是SPA应用，URL变化后需要刷新才能注入content script。

### Q: 提示"未找到订单数据"？
A: 京东后台DOM结构可能更新，请检查选择器是否匹配。可以按F12打开开发者工具，查看订单表格的class名称。

### Q: 同步失败怎么办？
A: 
1. 确认后端服务已启动
2. 检查服务器地址是否正确
3. 确认账号密码正确
4. 查看浏览器控制台错误信息

### Q: 能自动翻页抓取吗？
A: 目前版本支持单页抓取，自动翻页功能正在开发中。你可以手动翻页后逐页抓取，插件会自动去重。

## 🔒 隐私说明

- 所有数据仅在你本地浏览器和你配置的服务器之间传输
- 不会向任何第三方发送数据
- 账号密码仅用于登录你自己的智查查系统
- Cookie和登录态保存在浏览器本地存储中

## 🤝 开发说明

### 调试方法
1. 打开 `chrome://extensions/`
2. 找到本扩展，点击「Service Worker」查看后台日志
3. 在京东订单页面按F12，Console中查看content script日志
4. 右键扩展弹窗 → 检查，可调试popup页面

### 适配京东DOM更新
如果京东后台页面结构变化导致抓取失败，修改 `content/content.js` 中的选择器：

```javascript
const selectors = [
  '.order-list',      // 订单列表容器
  '.order-table',
  // 添加新的选择器...
];
```
